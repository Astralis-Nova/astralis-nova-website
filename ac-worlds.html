New Player Launch Guide

Install the game, choose a community world, and enter safely. Start with the basic client and launcher; add plugins only after the unmodified game works.

On MEGA, choose the download arrow—not “Save to MEGA.” Scan downloads normally and never reuse an important password on an emulator server.

1

Use a Windows computer

The original Asheron’s Call client and the common community launchers are Windows software. Keep the game in a normal writable folder such as C:\Turbine\Asheron's Call.

2

Install the AC client

Follow ACEmulator’s official How to Play page for its current approved client sources. Run the installer using its default location unless you have a reason to change it.

3

Apply End-of-Retail files

The official guide provides the current End-of-Retail client-file package. Copy its four files into the AC folder and choose Replace when prompted.

4

Install ThwargLauncher

Use the launcher linked by ACEmulator. In Browse Servers, choose a public world—or copy an address from AC Worlds and add it manually in Advanced View.

5

Create an account

Most ACE worlds create an account on the first successful login. Choose a unique username and password; do not reuse your email, banking, work, or other important password.

6

Enter Dereth

Select the world, enter the new credentials and press Launch. Read that server’s website or Discord first because account limits, botting rules and custom files vary.

ACE, GDLE and special client files

ACE worlds generally use the End-of-Retail client described in the official ACEmulator guide. Some GDLE/classic-era or heavily customized worlds require their own DAT files.

Never overwrite your working client blindly. Make a separate copy of the complete AC folder for a classic or custom world, then follow that world’s own website or Discord instructions.

Add a server manually
  1. Copy the server address from an AC Worlds card.
  2. Open ThwargLauncher and switch to Advanced View.
  3. Choose Edit Servers → Add Server.
  4. Enter the world name, host and port shown here.
  5. Select the emulator option required by the server, save it, then return to Simple View.

Decal and plugins—optional

Decal enables community plugins, maps and utilities, but it is not necessary for a first clean launch. Get the client working before installing Decal so troubleshooting has fewer moving pieces.

  • Use links supplied by established community projects or the chosen server.
  • Install one component at a time.
  • Check each server’s automation and botting rules before enabling plugins.
  • Do not run unfamiliar executables merely because someone posted them in chat.
Common first-launch fixes
  • DirectX or full-screen error: at character selection, press Alt+Enter to switch to windowed mode. ACEmulator also documents changing FullScreen=True to FullScreen=False in UserPreferences.ini.
  • Red X or server unavailable: confirm the host and port, check AC Worlds status, and visit the server Discord.
  • Login rejected: the world may require registration, have an account limit, or use a different client package.
  • Wrong graphics or missing portal data: confirm you installed the proper End-of-Retail or server-specific DAT files.

How the readings work

Server details come from the community-maintained AC server list and TreeStats. Recent character reports are not guaranteed to represent unique people. A stale reading remains visibly marked instead of pretending to be live.

  • Online: confirmed by the monitor or supported by a recent report.
  • Unknown: no dependable recent status.
  • Offline: explicitly reported down by the status source.
